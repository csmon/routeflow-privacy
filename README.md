# RouteFlow Privacy Policy

Public privacy-policy site for the RouteFlow Android app.

The published site is intended for:

- Google Play privacy-policy URL
- Google AdMob / UMP Privacy & messaging
- RouteFlow's in-app Privacy Policy link

The site intentionally contains no analytics, advertising tags, or consent-dependent scripts.
